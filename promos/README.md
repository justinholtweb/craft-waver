# Plugin Store promo images

Marketing images for the Waver listing on the Craft Plugin Store, rendered in the same theme as the
plugin's marketing page at
[justinholt.com/plugins/craft-waver](https://justinholt.com/plugins/craft-waver).

## Building

```bash
./build.sh          # all slides
./build.sh "2 5"    # just slides 2 and 5
```

Output lands in `out/` as `waver-promo-N.png`, 1920×1080 (rendered at 2× in headless Chrome, then
downsampled so the type stays crisp).

Every slide is pure CSS and type — there are no control-panel screenshots yet. When the CP settles,
screenshot slides can be added alongside these without redoing anything: copy the `.shot` /
`.viewport` pattern from `craft-appleseed-website/promos/slides.html`.

## Editing

Everything lives in `slides.html` — one `<section class="slide">` per image. The palette and fonts
are the plugin site's: accent `#3FC4B0`, deep tone `#12405A`, Jersey 20 for display, Inter for body.
The accent is the *light* teal because the plugin site's theme is dark — `#12405A` as a text colour on
it comes out at 1.7:1 and is effectively invisible.

Slides are absolutely 1080px tall with `overflow: hidden`, so **content that outgrows the slide is
silently clipped rather than scrolled** — slide 2 lost its balance row that way. Re-render and look
at the PNG after any copy change; the browser will not tell you.

`assets/` holds the fonts and two icon files:

- `icon.svg` — the app icon, used for the cover mark and the footer lockup. Copy it from
  `../src/icon.svg` whenever the icon changes.
- `watermark.svg` — the wave stroke only, with the icon's frame *and* its ledger rules stripped.
  Both are a few pixels thick in a 100-unit box, which at watermark scale becomes ~70px slabs that
  read as hard-edged grey boxes across the slide. A single stroke is the only part of this mark that
  survives being blown up and faded to 5%.

`fonts.css` is generated by `build.sh` (the woff2 files are base64-inlined so Chrome's `file://`
origin rules can't block them) and is not checked in.
